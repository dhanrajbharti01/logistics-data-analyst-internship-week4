# Logistics Data Analyst Internship - Week 4

## Predictive Modeling and Optimization in Logistics Systems

This repository contains my Week 4 work for the Logistics Data Analyst Internship, focusing on predictive modeling and optimization using Python.

### 📌 Project Overview

The objective of this task is to build predictive models for estimating actual delivery time using logistics operational data. The analysis compares Linear Regression and Random Forest Regression models and evaluates their performance using standard regression metrics.

### 📊 Dataset

The dataset contains 60 logistics order records with variables including:

- Order ID
- Distance (km)
- Parcel Count
- Traffic Level
- Hour
- Vehicle Capacity
- Planned Time (min)
- Actual Time (min)

### 🤖 Models Implemented

1. Linear Regression
2. Random Forest Regression

### 📈 Evaluation Metrics

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)
- 5-Fold Cross-Validation
